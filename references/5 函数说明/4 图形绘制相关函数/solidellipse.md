# solidellipse

这个函数用于画无边框的填充椭圆。
    
    
    void solidellipse(
    	int left,
    	int top,
    	int right,
    	int bottom
    );
    

## 参数

### left

椭圆外切矩形的左上角 x 坐标。

### top

椭圆外切矩形的左上角 y 坐标。

### right

椭圆外切矩形的右下角 x 坐标。

### bottom

椭圆外切矩形的右下角 y 坐标。

## 返回值

无

## 备注

该函数使用当前填充样式绘制无边框的填充椭圆。

由于屏幕像素点坐标是整数，因此用圆心和半径描述的椭圆无法处理直径为偶数的情况。而该函数的参数采用外切矩形来描述椭圆，可以解决这个问题。

当外切矩形为正方形时，可以绘制填充圆。
