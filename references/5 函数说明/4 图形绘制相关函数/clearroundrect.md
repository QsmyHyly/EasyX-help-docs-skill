# clearroundrect

这个函数用于清空圆角矩形区域。
    
    
    void clearroundrect(
    	int left,
    	int top,
    	int right,
    	int bottom,
    	int ellipsewidth,
    	int ellipseheight
    );
    

## 参数

### left

圆角矩形左部 x 坐标。

### top

圆角矩形顶部 y 坐标。

### right

圆角矩形右部 x 坐标。

### bottom

圆角矩形底部 y 坐标。

### ellipsewidth

构成圆角矩形的圆角的椭圆的宽度。

### ellipseheight

构成圆角矩形的圆角的椭圆的高度。

## 返回值

无

## 备注

该函数使用当前背景色清空圆角矩形区域。
