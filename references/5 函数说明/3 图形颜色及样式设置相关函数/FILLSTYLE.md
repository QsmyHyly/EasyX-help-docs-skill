# FILLSTYLE  
  
填充样式对象。
    
    
    class FILLSTYLE();
    

## 公有成员

### int style;

填充形式，详见 [setfillstyle](setfillstyle.htm) 函数重载的 style 参数。

### long hatch;

填充图案样式，详见 [setfillstyle](setfillstyle.htm) 函数重载的 hatch 参数。

### IMAGE* ppattern;

填充图像，详见 [setfillstyle](setfillstyle.htm) 函数重载的 ppattern 参数。

## 备注

参数的详细含义及使用方法请参考 [setfillstyle](setfillstyle.htm) 函数。

## 示例

请参考 [setfillstyle](setfillstyle.htm) 函数中的示例。
