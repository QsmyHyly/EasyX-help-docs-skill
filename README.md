# EasyX 文档技能

提供 EasyX 库的文档查阅功能，包括基本概念、函数说明、示例程序和常见问题。

## 简介

这是一个为 AI 助手设计的技能包，帮助用户快速获取 EasyX 图形库相关的编程参考资料。

## 功能特性

- 📖 **基本概念**：颜色、坐标、设备等核心概念说明
- 📚 **函数查询**：详细的函数文档，按类别组织
- 💻 **示例程序**：实用的代码示例和教程
- ❓ **常见问题**：使用 EasyX 时遇到的常见问题及解决方案

## 文档结构

## 使用场景

当用户询问以下类型的问题时可使用此技能：

- EasyX 的基本概念和工作原理
- 特定函数的用法、参数或返回值
- 如何实现特定图形功能
- 编译或运行时的常见问题
