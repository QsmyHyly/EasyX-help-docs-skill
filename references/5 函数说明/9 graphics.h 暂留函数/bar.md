# bar  
  
这个函数用于画无边框填充矩形。
    
    
    void bar(
    	int left,
    	int top,
    	int right,
    	int bottom
    );
    

## 参数

### left

矩形左部 x 坐标。

### top

矩形顶部 y 坐标。

### right

矩形右部 x 坐标。

### bottom

矩形底部 y 坐标。

## 返回值

无

## 备注

该函数已废弃，仅在 graphics.h 中声明，推荐使用 [solidrectangle](../4%20图形绘制相关函数/solidrectangle.htm) 替代该函数。
