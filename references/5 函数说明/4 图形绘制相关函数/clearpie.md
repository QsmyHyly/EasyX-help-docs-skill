# clearpie

这个函数用于清空扇形区域。
    
    
    void clearpie(
    	int left,
    	int top,
    	int right,
    	int bottom,
    	double stangle,
    	double endangle
    );
    

## 参数

### left

扇形所在椭圆的外切矩形的左上角 x 坐标。

### top

扇形所在椭圆的外切矩形的左上角 y 坐标。

### right

扇形所在椭圆的外切矩形的右下角 x 坐标。

### bottom

扇形所在椭圆的外切矩形的右下角 y 坐标。

### stangle

扇形的起始角的弧度。

### endangle

扇形的终止角的弧度。

## 返回值

无

## 备注

该函数使用当前背景色清空扇形区域。
