# arc  
  
这个函数用于画椭圆弧。
    
    
    void arc(
    	int left,
    	int top,
    	int right,
    	int bottom,
    	double stangle,
    	double endangle
    );
    

## 参数

### left

圆弧所在椭圆的外切矩形的左上角 x 坐标。

### top

圆弧所在椭圆的外切矩形的左上角 y 坐标。

### right

圆弧所在椭圆的外切矩形的右下角 x 坐标。

### bottom

圆弧所在椭圆的外切矩形的右下角 y 坐标。

### stangle

圆弧起始角的弧度。

### endangle

圆弧终止角的弧度。

## 返回值

无
