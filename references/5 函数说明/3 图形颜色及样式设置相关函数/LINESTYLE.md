# LINESTYLE

画线样式对象。
    
    
    class LINESTYLE();
    

## 公有成员

### DWORD style;

画线样式，详见 [setlinestyle](setlinestyle.htm) 函数的 style 参数。

### DWORD thickness;

线的宽度，以像素为单位。

### DWORD* puserstyle;

用户自定义样式数组，详见 [setlinestyle](setlinestyle.htm) 函数的 puserstyle 参数

### DWORD userstylecount;

用户自定义样式数组的元素数量。

## 备注

参数的详细含义及使用方法请参考 [setlinestyle](setlinestyle.htm) 函数。

## 示例

请参考 [setlinestyle](setlinestyle.htm) 函数中的示例。
